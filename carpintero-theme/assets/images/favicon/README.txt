CARPETA: FAVICON

Ficheros esperados:
  favicon.svg           (versión vectorial, preferida)
  favicon-32.png        (32x32)
  favicon-16.png        (16x16)
  apple-touch-icon.png  (180x180)
  android-chrome-192.png (192x192)
  android-chrome-512.png (512x512)

Recomendación:
- Diseña un icono simple (inicial, herramienta, o símbolo de madera).
- Funciona bien en cuadrado.
- Usa https://realfavicongenerator.net/ para generar todos los tamaños a partir de un SVG.
